Panduan Ekstraksi Data

Ikuti 4 langkah interaktif ini untuk menjalankan analisis sentimen menggunakan sistem otomatisasi kami.

1. Isi Parameter Analisis

Buka halaman Analisis. Tentukan jumlah maksimal tweet yang ingin dianalisis dan ketik kata kunci yang ingin dicari. Setelah itu, klik tombol "Lihat Hasil Analisis Sentimen dan Emosi".

2. Login via Akun Google (Wajib)

Sistem akan otomatis membuka browser Google Chrome baru untuk mengakses X (Twitter). Di browser tersebut, lakukan login ke akun Anda. Sangat disarankan untuk memilih opsi "Sign in with Google". Hindari mengetik username dan password secara manual karena sistem keamanan X sering kali memblokirnya.

3. Deteksi Otomatis

Setelah Anda berhasil login dan melihat halaman Beranda (Home) X di browser, jangan tutup browser tersebut! Sistem kami akan mendeteksi keberhasilan login Anda secara otomatis dalam beberapa detik dan langsung memulai proses pencarian data.

4. Biarkan Robot Bekerja

Sistem Selenium kami akan mengambil alih browser secara otomatis untuk mengumpulkan data tweet, membersihkannya, dan memasukkannya ke dalam Model IndoBERT. Anda cukup bersandar santai hingga browser tertutup sendiri dan hasil visualisasi (Wordcloud & Pie Chart) muncul di layar Anda!
