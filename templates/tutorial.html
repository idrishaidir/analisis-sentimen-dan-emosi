Cara Mendapatkan Auth Token

Ikuti 5 langkah mudah ini untuk mendapatkan AUTH token X anda.

1. Buka Akun X

Login dan buka halaman utama akun X (Twitter) Anda di browser.

2. Buka Inspect

Klik kanan di mana saja pada halaman, lalu pilih "Inspect". Anda juga bisa menggunakan shortcut keyboard Ctrl+Shift+I.

3. Cari Menu Application

Di panel 'Inspect' yang muncul, cari dan klik tab "Application". (Mungkin tersembunyi di bawah panah »).

4. Temukan Auth Token

Di menu sebelah kiri, buka "Cookies" > "https://x.com". Di daftar yang muncul, cari nama auth_token dan klik. Salin (copy) kode panjang di bagian "Cookie Value".

5. Tempel Token

Kembali ke halaman Analisis, dan tempel (paste) kode yang sudah Anda salin ke dalam input "Masukkan auth token".
